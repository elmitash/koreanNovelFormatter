# Korean Novel Formatter (줄바꿈 자동 보정 및 무결성 검증기)

이 도구는 과거 PC통신 시절의 텍스트 파일이나 하드랩(Hard-wrapped) 처리된 한국어 소설 텍스트에서 **불필요한 줄바꿈(강제 개행)을 자연스럽게 이어 붙이고 띄어쓰기를 지능적으로 교정**하는 오픈소스 자동 보정 도구입니다.

국산 고성능 한국어 형태소 분석기인 **Kiwi(지능형 한국어 형태소 분석기)**를 기반으로 동작하여 기존의 단순 규칙 기반 도구들보다 월등히 정교한 한국어 문법 분석 결과를 제공합니다.

## 🥝 Kiwi 형태소 분석기란?

본 프로젝트는 한국어 줄바꿈 경계면을 매끄럽게 교정하고 단락을 복원하기 위해 국산 고성능 형태소 분석기인 **Kiwi**를 핵심 엔진으로 사용합니다.

### 왜 Kiwi를 사용하나요?
* **지능형 공백 복원 (`Kiwi.glue`)**: 단순 정규식 기반 치환과 달리, 결합 부위 전후 형태소들의 관계(예: 체언과 조사, 어근과 어미 등)를 형태소 수준에서 엄밀하게 분석하여 공백 유무를 정확하게 결정합니다.
* **압도적인 가볍고 빠른 성능**: 딥러닝 기반 맞춤법 교정 모델(예: TensorFlow 등을 요구하는 무거운 모델)과 달리, C++ 고성능 코어와 통계적 언어 모델을 활용해 아치 리눅스를 비롯한 미니멀한 환경에서도 극적인 속도로 대용량 소설을 지연 없이 분석합니다.
* **유연한 사전 확장성**: 판타지, 무협 소설 등 특수 도메인에서 끊임없이 변형되는 고유 사칭 단어들을 외부 사용자 정의 사전(`user_words.txt`)을 통해 완벽하게 통제할 수 있습니다.
* **[Kiwi 공식 GitHub 저장소](https://github.com/bab2min/Kiwi)**: C++ 기반으로 개발되어 극도로 가볍고 빠른 속도를 자랑하는 지능형 한국어 형태소 분석기입니다.
* **[kiwipiepy 공식 GitHub 저장소](https://github.com/bab2min/kiwipiepy)**: Python 환경에서 Kiwi 엔진의 강력한 기능들을 손쉽게 제어할 수 있도록 래핑된 공식 Python 패키지입니다.

## 🌟 주요 특징

1. **지능형 형태소 결합 (`Kiwi.glue`)**
   * 줄바꿈 경계면의 형태소 구조(명사+조사, 용언 어근+어미 관계 등)를 실시간으로 분석하여, 공백 없이 붙여 쓸지 공백을 두고 띄어 쓸지 지능적으로 판단합니다.
2. **외부 사용자 사전 지원 (`user_words.txt`)**
   * 판타지/무협 소설에 자주 등장하는 고유 명사나 설정 용어들을 외부 텍스트 파일로 자유롭게 관리할 수 있습니다. 이를 통해 고유 명사가 포함된 주변 문장의 띄어쓰기 정확도를 극대화합니다.
3. **100% 무결성 검증 시스템 내장**
   * 원본 파일과 변환된 파일에서 모든 공백 문자(스페이스, 탭, 개행)를 제거한 순수 알맹이 글자들을 1대1 캐릭터 수준에서 완벽하게 비교합니다.
   * 혹시 모를 글자 유실, 왜곡, 중복 결합 오류를 차단하며, 오류 발생 시 첫 불일치 지점의 앞뒤 맥락을 보여줍니다.
4. **완벽한 크로스 플랫폼 & 투명한 오픈소스**
   * 기존의 윈도우 전용 실행 파일(`CRAutoFix` 등)과 달리, 파이썬이 설치된 환경(Linux, macOS, Windows)이라면 어디서든 구동 가능하며 백신 오진 우려가 전혀 없습니다.
5. **하위 폴더 일괄 처리(Batch Processing)**
   * 지정한 폴더 내의 모든 하위 폴더를 재귀적으로 탐색하여 대상 `.txt` 파일들을 일괄 처리합니다. 이미 정리된 파일(`*_정리.txt`)은 알아서 건너뜁니다.

## 📊 기존 도구와의 비교 (vs CRAutoFix)

| 비교 항목 | CRAutoFix | **Korean Novel Formatter (본 도구)** |
| :--- | :--- | :--- |
| **분석 방식** | 규칙 기반 알고리즘 | 현대적 NLP 형태소 분석 (`Kiwi` 형태소 트리 최적 분석) |
| **플랫폼 지원** | Windows 전용 | Linux, macOS, Windows (크로스 플랫폼) |
| **소스 공개 여부** | 비공개 (EXE 배포, 백신 오진 잦음) | 100% 투명한 파이썬 오픈소스 스크립트 |
| **사용자 사전** | 제한적/어려움 | `user_words.txt` 텍스트 편집으로 무제한 관리 가능 |
| **유실 검증 장치** | 없음 (수동 점검 필요) | 내장된 글자 누락 검증 프로세스로 유실 제로 보장 |

## 🛠️ 요구 사항 및 설치 방법

이 프로그램을 구동하려면 Python 3 환경과 `kiwipiepy` 형태소 분석기 라이브러리가 필요합니다.

```bash
# 가상 환경 생성 및 활성화 (선택)
python -m venv .venv
source .venv/bin/activate       # Bash/Zsh 환경
# source .venv/bin/activate.fish # Fish 쉘 환경

# 필수 라이브러리 설치
pip install kiwipiepy
